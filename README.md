# mapillary-blackvue  

A script that simplifies uploads of videos from blackvue 900 series dashcams to mapillary

## Prerequisites  

mapillary_tools  
ffmpeg  
exiftool  
keyring  
  
## Usage  

Copy Blackvue videos to directory - note this will create images for each second of video.  A lot of space will be needed.  
During the first run, mapillary tools will request your log-in info  
  
Some of this upload functionality may now be available through mapillary tools directly
